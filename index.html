The Tizen OS Technology Stack

We leverage the full depth of the Samsung TV SDK and platform APIs, avoiding bulky generic libraries to maximize TV processor efficiency.

Core Platforms
  • Tizen WebApp (.wgt): W3C HTML5/CSS3/ES2022+ with zero browser overhead
  • Tizen .NET (.tpk): C# with high-performance Samsung NUI framework
  • Samsung SSSP: Smart Signage Platform 6, 7, and 10+
  • TV Profiles: Full support for 2018 (Tizen 4.0) through 2026 (Tizen 8.0+) models
Media & Streaming
  • Samsung AVPlay API: Low-level hardware video decoding
  • DRM Implementations: Microsoft PlayReady, Google Widevine Modular
  • Protocols: HLS (m3u8), MPEG-DASH (mpd), SmoothStreaming, Low-Latency WebRTC
  • Audio Architecture: Dolby Digital Plus, Dolby Atmos, Multichannel PCM
10-Foot TV Ergonomics
  • Spatial Navigation: Pure deterministic focus management with memory retention
  • Key Event Matrix: Return/Back key compliance, TV Channel Up/Down, Media Keys
  • Dynamic Viewport: Resolution scaling from Full HD (1080p) to 4K UHD & 8K
  • Smart Hub Integration: Preview tiles, deep linking, and Samsung voice controls
Tooling & Quality
  • Diagnostics: SDB bridge, remote dlog analysis, web inspector CDP
  • Profiling: Memory leak isolation, canvas performance, JS heap benchmarking
  • Compliance: Samsung Seller Office QA checklist, Samsung CA signing profiles
  • Automated Testing: Playwright connectOverCDP automated TV UI testing
